Matematika 2: Aljabar Linier & Geometri

Slide perkuliahan interaktif modern berbasis web yang diparafrase dan diselaraskan untuk kurikulum komputasi praktis, dilengkapi simulasi animasi matematika dan notasi KaTeX.

Dosen Pengampu: Aditya Pratama  •  Referensi Utama: Rinaldi Munir (STEI ITB) & Howard Anton
ALGEO 00 • 12 SLIDES • LIVE CANVAS & LATIHAN IR
Pengantar Aljabar Linier & Geometri Komputasi
Motivasi pentingnya aljabar linier bagi mahasiswa informatika UNU Kalbar, 6 pilar aplikasi riil (Grafika 3D, Vector Space Model IR, Face Recognition, Quaternion Game, LLM / AI, Quantum), simulasi interaktif rotasi matriks 2D di browser, serta contoh latihan perhitungan Cosine Similarity & transformasi matriks.
⏱ Estimasi: 45 - 55 menit Buka Materi
ALGEO 02 • 11 SLIDES • SIMULATOR OBE & LATIHAN 8 MATRIKS
Matriks Eselon: Konsep REF & RREF
Konsep 1 Utama (Leading 1), 3 Sifat Matriks Eselon Baris (REF), Sifat ke-4 Eselon Baris Tereduksi (RREF), simulator langkah demi langkah Operasi Baris Elementer (OBE) langsung di slide, serta koleksi latihan identifikasi 8 matriks (Howard Anton) dan reduksi matriks bertahap.
⏱ Estimasi: 50 - 65 menit Buka Materi

Aplikasi Simulasi & Visualisasi Python (Desktop GUI)

Tersedia aplikasi desktop mandiri berbasis Python (Tkinter + Matplotlib + NumPy) untuk mendemonstrasikan animasi transformasi geometri 2D, proses OBE step-by-step, dan Cosine Similarity pada proyektor kelas:

python "Matematika 2 - Aljabar Linear\simulasi_algeo_interaktif.py"
Navigasi Keyboard Gunakan tombol → / Spasi untuk maju dan ← untuk mundur
Mode Layar Penuh Proyektor Tekan tombol F untuk presentasi layar penuh di ruang kuliah
