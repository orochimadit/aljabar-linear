Algeo 00 12 Slides Live Canvas
Pengantar Aljabar Linier & Geometri Komputasi
Pentingnya aljabar linier bagi mahasiswa informatika UNU Kalbar, 6 pilar aplikasi riil (Grafika 3D, Vector Space Model IR, Face Recognition, Quaternion Game, LLM / AI, Quantum), simulasi interaktif rotasi matriks 2D di browser, serta contoh latihan perhitungan Cosine Similarity & transformasi matriks.
Estimasi: 45 - 55 menit Buka Materi
Algeo 02 11 Slides Simulator OBE
Matriks Eselon: Konsep REF & RREF
Konsep 1 Utama (Leading 1), 3 Sifat Matriks Eselon Baris (REF), Sifat ke-4 Eselon Baris Tereduksi (RREF), simulator langkah demi langkah Operasi Baris Elementer (OBE) langsung di slide, serta koleksi latihan identifikasi 8 matriks dan reduksi bertahap.
Estimasi: 50 - 65 menit Buka Materi

Aplikasi Simulasi & Visualisasi Python (Desktop GUI)

Tersedia aplikasi desktop mandiri berbasis Python (Tkinter + Matplotlib + NumPy) untuk mendemonstrasikan animasi transformasi geometri 2D, proses OBE bertahap, dan Cosine Similarity pada proyektor kelas:

python simulasi_algeo_interaktif.py
Navigasi Keyboard Gunakan tombol Spasi untuk maju dan Backspace untuk mundur.
Mode Layar Penuh Proyektor Tekan tombol F untuk presentasi layar penuh di ruang kuliah.
Simulator Komputasi Interaktif Dilengkapi visualisasi animasi matriks langsung di browser tanpa perlu server tambahan.
